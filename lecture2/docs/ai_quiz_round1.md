# AI 对拍练习 Round 1 —— 分歧清单

> 范围：空安全（`?`、`?.`、`??`、`!`、`late`）、命名参数（`required`、默认值、位置参数与命名参数混用）、整除（`/` 与 `~/`，含负数）

## 复核结论

5 题全部正确，无实质性分歧。

- 题 2 的报错文案少了 `variable` 是 Dart 实际输出与口述习惯的差异，属于非实质性出入。
- 题 5 对“负数向零截断而非向下取整”的把握准确，这是本课整除部分最关键的易错点（Python 等语言的 `//` 是向下取整，Dart 的 `~/` 是向零截断，跨语言易混）。

## 关键知识点回顾

1. **`?.` 会把表达式“传染”为可空**，需要配合 `??` 给默认值才能当非空类型使用。
2. **`late` 把检查从编译期推迟到运行期**：只要赋值路径有可能被执行（如包在 `if` 里），编译器就不会拦截，运行时若未赋值则抛 `LateInitializationError`。
3. **`required` 是编译期约束**：漏掉必填命名参数，`dart run` 在编译阶段即失败，不会到运行时。
4. **位置参数必须在命名参数之前**；命名参数的调用顺序任意。
5. **`/` 结果恒为 `double`**（如 `4 / 2` 得 `2.0`），需要整数结果用 `~/`。
